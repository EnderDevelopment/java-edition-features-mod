# Java Edition Features Mod

Bring Java Edition mechanics to Minecraft Bedrock Android

## Features

- Java-style combat with attack cooldown indicator
- Zoom feature for a more immersive gameplay experience
- Health regeneration for players
- Item drop handler for quick item management
- Air click hand swing for a more authentic combat feel
- Crouching with shield to prevent sprinting while blocking

## Requirements

- Minecraft Bedrock Edition on Android
- Fabric Loader
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/java-edition-features-mod/releases)
2. Place the mod file in your `mods` folder
3. Launch Minecraft Bedrock Edition with Fabric Loader

## Usage

- Press the `Z` key to zoom in
- Press the `Q` key to drop the item in your main hand
- Crouch while holding a shield to prevent sprinting

## Configuration

The mod does not have any configuration files. All features are enabled by default.
